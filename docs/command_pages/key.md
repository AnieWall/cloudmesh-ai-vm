# cmx key

## Overview

Manage SSH keys for VM access.

### Sub‑commands

- `upload KEY_PATH` – Upload a public SSH key to the cloud provider. Use `--name TEXT` to provide a custom name.
- `list` – List all SSH keys for the current provider.
- `delete KEY_NAME` – Delete an SSH key from the provider.

## Usage

```bash
cmx key <subcommand> [options]
```
